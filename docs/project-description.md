# Project Description

## Overview
This project is designed to track fabrics throughout different stages of production, including production, dyeing, quality control, and shipping.

## Objective
The main objective is to create a structured system that monitors fabric status and improves traceability in the production process.

## Design Approach
The system is implemented using object-oriented programming in C++ and applies the State Design Pattern to represent different stages of the fabric lifecycle.

## Features
- Tracks fabric through multiple stages
- Models real production flow
- Uses state-based behavior

## Future Work
- Adding database integration
- Expanding system functionality
- Improving user interface
