# Fabric Production Tracking System

## Project Overview
This project is designed to track fabrics throughout the production lifecycle in a supply chain system. Each fabric goes through multiple stages such as production, dyeing, quality control, and shipping.

## Problem
Managing fabric production manually can lead to inconsistencies and lack of traceability. This system aims to provide a structured way to track fabric status.

## Solution
The system models the lifecycle of fabrics using object-oriented programming and applies the State Design Pattern to represent different production stages.

## Design Pattern
State Pattern is used to manage transitions between fabric states such as Produced, Dyed, Quality Checked, and Shipped.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- UML Diagrams
