# Production Tracking Application
 
## Project Overview
 
This project is a Production Tracking Application designed for employees working in a clothing distribution company. The purpose of the system is to track the location and status of fabrics and production materials inside a warehouse environment.
 
In large distribution centers, employees often experience difficulties locating materials quickly. This application aims to simplify the tracking process and improve operational efficiency.
 
 
## Problem Statement
 
Warehouse employees sometimes struggle to identify where fabrics or production items are located. This can lead to delays, confusion, and inefficient workflow in the production process.
 
 
## Proposed Solution
 
The Production Tracking Application allows employees to:
 
- Track fabric and material locations

 - Update production status

 - Monitor inventory inside the warehouse

 - Assign and manage tasks related to production
 
The system will provide a clear overview of production materials and help employees access information quickly.
 
 
## System Architecture
 
The system is designed using a combination of:
 
- Layered Architecture
 
This approach helps improve scalability, maintainability, and flexibility of the system.
